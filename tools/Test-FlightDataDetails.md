# 飞行数据页逐项复测

只使用本机 ArduPlane SITL 和独立 `-datadir`。若从日常配置复制 config.xml，必须将隔离配置的 `logdirectory` 同时改到测试目录；显式日志路径优先于默认运行目录。不得连接真实设备、强制解锁、修改 ARMING_CHECK 或执行起飞。

## 已保存的自动回归

`Test-FlightDataLogDownload.py` 用 MP 内置 IronPython 的 `-script` 入口运行，连接本机 TCP 5760；`MP_FD_DETAIL_OUTPUT` 指定结果目录。每次使用独立日志子目录，避免重复下载触发原重名提示。

本轮记忆检查的前置状态：在隔离配置中，快速视图数量设为2列2行；HUD右键添加alt自定义字段，电池设4串并开启单节显示，正常保存后重启。脚本核对这些真实保存的设置，然后测试AUX三档、连接统计刷新及带IronPython事件订阅的DataFlash下载。SITL须有至少一份已完成BIN日志；可以正常解锁后锁定生成，若被拒绝须先记录原因，不强制。

下载测试同时用只读后台观察者打开新出现的BIN（FileShare.ReadWrite），验证文件最终发布不会再被后续重命名阻塞。下载期间通过飞行数据按钮切换STABILIZE，并用参数API写入AIRSPEED_CRUISE后读回和恢复；记录执行时下载是否仍在运行。此处不是全部参数表UI写入测试，也不能代替低速无线链路验收。

输出 `retest-result.txt` 的PASS、`retest-status.txt` 的0、`retest-events.txt` 和 `retest-health.csv`。包龄是距最近有效报文的时间，不是网络往返延迟。只读占用复现仅证明该并发场景，不证明历史未捕获异常的全部原因。

## 其他实际页面复测步骤

1. **AUX与解锁**：动作页先设STABILIZE，辅助功能选择51 MANUAL。依次点击Low/Mid/High；前两档应保持STABILIZE，High切Manual，检查DO_AUX_FUNCTION的三个ACK。正常解锁若被拒绝，记录飞控文字并取消强制；稳定后再次正常解锁、锁定，核对armed及Throttle armed/disarmed，始终留在地面。
2. **脚本**：用临时脚本每200ms打印计数并写临时计数文件。通过原文件选择按钮加载，勾输出重定向、运行，观察输出窗口计数增长；点击停止后计数不再增长、运行按钮恢复。编辑验证使用单独无副作用文件，核对系统实际打开的编辑器窗口标题/文件路径，不能仅凭按钮无异常判断通过。
3. **遥测日志**：核对自动记录文件非空。断开SITL后原按钮加载本轮tlog，播放观察文件位置和日志时间推进，暂停后等待位置保持不变；进度拖到25%核对文件位置，分别1x/5x观察相同墙钟时间内日志时间推进，最后暂停。不得只检查速度标签。
4. **DataFlash**：用原MAVLink下载窗口列出并选择日志下载，核对下载字节数等于LOG_ENTRY。原打开按钮选择BIN，勾ATT.Roll，核对实际曲线点数；原BIN转LOG按钮转换，核对文本含FMT和ATT等可解析记录，非仅文件存在。
5. **快速/HUD**：双击一个仍保留的数值格更换字段，右键改格数；HUD右键增字段并设置电池串数/单节显示。保存重启后检查实际字段、格数和HUD设置，不只检查配置文件。
6. **实时曲线与状态**：打开实时曲线、双击选择新字段，观察点数和数值增长；消息页应展示飞控文字，状态页应展示对应实时字段。HUD独立窗口和F5可按既有Test-FlightDataScope.py复测。
7. **统计**：打开连接统计后等待至少6秒，核对收发速率、包数、质量等已更新；初次空字段不能当作全部统计通过。

截图必须核对实际内容。WinForms DrawToBitmap可用于普通控件，OpenGL HUD空白区域不能当作HUD渲染证据。日志上传、改写参数等操作结束后恢复本次修改的模拟器参数，仅关闭本次测试进程。
